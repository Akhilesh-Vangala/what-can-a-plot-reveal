# Human readers — formative expert sessions

4–6 qualitative expert sessions (think-aloud on 12 plots, an Explorer task, a short interview), reported as themes and
quotes only; no statistics. Full protocol: `PROTOCOL.md`.

1. `python code/make_human_study.py` re-trains held-out confirmatory models from their seeds and renders the plot pool
   (standard and redesigned versions); `python code/make_formative.py` picks the 12 session plots →
   `formative/plots/P01–P12.png` (true states in `formative/key.json`, not published).
2. Run each session with the protocol; one notes file per participant (code E1, E2, ...); no names, no recordings.
3. Code the notes into the four themes in `PROTOCOL.md`.
